# LUMÉRA — Luxury Makeup Demo Website

A premium, demo makeup brand website built by **AKCLNT** — designed around a cinematic gold-radiance hero video.

## ✨ Features
- **Full-screen hero video** (autoplay, muted, loop) with poster fallback
- Working **shopping bag** — add products, quantity +/-, totals, localStorage persistence, slide-in cart drawer
- Interactive **Shade Finder** — tap a swatch, lip colour/details update live
- Bestsellers shop grid, categories, ritual/story section, reviews, Instagram gallery, newsletter (demo code: `GLOW10`)
- Fully **responsive**, scroll-reveal animations, sticky glass header

## 🚀 Run / Deploy
- Just open `index.html` — no build step, no dependencies.
- **Vercel:** import this repo at vercel.com → Deploy (framework: Other / static).
- **GitHub Pages:** Settings → Pages → Deploy from `main` branch.

## 📁 Structure
```
index.html      — page
style.css       — design system (champagne gold / cream / serif)
script.js       — products, shades, cart logic
assets/hero.mp4 — hero video
assets/poster.jpg / model.jpg — frames extracted from the hero video
```
